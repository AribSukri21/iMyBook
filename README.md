
# iMyBook - Reading Book Application

## Project Overview

iMyBook is a simple desktop application developed
using Electron, HTML, CSS and JavaScript.

The application allows users to search for books,
receive book suggestions and manage a personal
reading list.

## Main Features

- Search books using the Open Library API
- Display book information
- Suggest books based on reading categories
- Add, view, edit and delete reading records
- Calculate reading progress
- Save reading records using Local Storage

## Technologies

- Electron
- HTML
- CSS
- JavaScript
- JSON
- Open Library API
- Local Storage

## How to Run

1. Install Node.js.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run: npm install
6. Run: npm start

## Internet Requirement

An internet connection is required to search
for books and retrieve suggestions.

Saved reading records can be viewed offline.
